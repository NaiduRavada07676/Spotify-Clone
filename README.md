# 🎵 Spotify Clone

A modern **Spotify-inspired music streaming UI clone** built using **HTML5 and CSS3**.

This project recreates the visual layout of a music streaming platform with a dark-themed interface, sidebar navigation, playlists, albums, music cards, and a responsive design.

> ⚠️ This project is created for educational and frontend practice purposes. It is not affiliated with or endorsed by Spotify.

## ✨ Features

- 🎵 Spotify-inspired user interface
- 🌙 Dark theme
- 📚 Sidebar navigation
- 🏠 Home section
- 🔍 Search interface
- 🎶 Music cards
- 💿 Album sections
- 📋 Playlist section
- 🎧 Popular music section
- ▶️ Music player UI
- 📱 Responsive design
- ✨ Clean and modern layout
- 🖥️ Desktop-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
